セッションA 配置スケジュール（牡蠣→箱、20本）
指示文: "pick up the white oyster plush and put it in the box"
毎エピソード、牡蠣と袋を下記の位置に置いてから録画開始。両方必ず机の上に置く（袋は掴まないがdistractorとして映す）。

Ep01: 牡蠣=中央   / 袋=右奥
Ep02: 牡蠣=左奥   / 袋=中央
Ep03: 牡蠣=中央   / 袋=右奥
Ep04: 牡蠣=右奥   / 袋=左奥
Ep05: 牡蠣=中央   / 袋=右奥
Ep06: 牡蠣=右奥   / 袋=中央
Ep07: 牡蠣=左手前  / 袋=左奥
Ep08: 牡蠣=右手前  / 袋=右奥
Ep09: 牡蠣=右奥   / 袋=右手前
Ep10: 牡蠣=左手前  / 袋=右奥
Ep11: 牡蠣=左手前  / 袋=右手前
Ep12: 牡蠣=右手前  / 袋=右奥
Ep13: 牡蠣=左奥   / 袋=中央
Ep14: 牡蠣=左奥   / 袋=左手前
Ep15: 牡蠣=左奥   / 袋=中央
Ep16: 牡蠣=右奥   / 袋=右手前
Ep17: 牡蠣=右手前  / 袋=右奥
Ep18: 牡蠣=左手前  / 袋=中央
Ep19: 牡蠣=中央   / 袋=左奥
Ep20: 牡蠣=右手前  / 袋=左奥

牡蠣位置の内訳: 左手前4/左奥4/中央4/右手前4/右奥4 = バランス済み
※位置は「だいたい」でOK。厳密でなくていいが、牡蠣を毎回同じ場所に置かないことが肝心
