# SO-101 正規組み立てガイド（公式準拠・作業チェックリスト版）

> 一次情報: LeRobot 公式ドキュメント <https://huggingface.co/docs/lerobot/so101>
> 部品表(BOM)・3Dプリント: [TheRobotStudio/SO-ARM100](https://github.com/TheRobotStudio/SO-ARM100)
> このファイルは公式手順を「手を動かしながら追える」形に再構成したもの。ネジ本数などの逐語は公式の記述を保持している。**細かい向き・はめ込みは必ず各工程の公式動画を見ること**（本文にリンクを明記）。

---

## 0. 全体像（最初に頭に入れる3点）

1. **アームは2本組む。** 動かされる側＝**Follower（追従アーム）**、人が握って動かす側＝**Leader（操作アーム）**。テレオペではLeaderを手で動かすとFollowerが同じ姿勢を再現する。
2. **モーターは同じに見えて中身が違う。** Followerは6個すべて同一（1/345ギア）。**Leaderは関節ごとにギア比が違う**（自重を支えつつ軽く動かすため）。→ **Leaderはどのモーターをどの関節に入れるかを間違えるとアウト**。§2の表が絶対。
3. **作業の順序は「①IDを焼く → ②機械組み立て → ③キャリブレーション」。** モーターIDの書き込み(EEPROM)は組み立て前に、モーター単体で行う。**一度焼けば再設定不要**。

作業フロー全体:

```
LeRobot導入 → ポート特定 → モーターID設定(Follower) → モーターID設定(Leader)
   → 機械組み立て(Joint1〜Gripper) → キャリブレーション(Follower→Leader) → 完成
```

## 1. 事前準備

### 1-1. 部品・工具

- [ ] 3Dプリント部品一式（サポート材付き）
- [ ] STS3215 モーター ×12（Follower用6 + Leader用6。**Leaderはギア比違いの3種**）
- [ ] コントローラーボード ×2（各アーム1枚。Waveshare等）
- [ ] 電源アダプタ ×2、USBケーブル ×2、3ピンケーブル一式
- [ ] ネジ: **M2×6mm（最小）** と **M3×6mm**、精密ドライバー
- [ ] ネジの正確な員数は公式BOM（SO-ARM100リポジトリ）で確認する

> ⚠️ **3Dプリンタが無い/初めての場合**は、公式が印刷代行やキット購入を案内している。SO-ARM100のREADME参照。

### 1-2. LeRobot と Feetech SDK を入れる

公式[Installation Guide](https://huggingface.co/docs/lerobot/installation)に従って LeRobot を導入後、Feetech（モーター）SDKを追加:

```bash
pip install -e ".[feetech]"
```

## 2. モーターのギア比マップ（Leaderは必ずこの通りに配置）

Followerは6個すべて **1/345** で共通。Leaderのみ関節ごとに以下のギア比を割り当てる:

| Leader関節（軸）          | モーターID | ギア比    |
| ------------------------- | :--------: | :-------: |
| Base / Shoulder Pan（土台/旋回） | 1     | 1 / 191  |
| Shoulder Lift（肩・上下）        | 2     | 1 / 345  |
| Elbow Flex（肘）                 | 3     | 1 / 191  |
| Wrist Flex（手首・曲げ）         | 4     | 1 / 147  |
| Wrist Roll（手首・回転）         | 5     | 1 / 147  |
| Gripper（グリッパ）              | 6     | 1 / 147  |

> 💡 モーター本体にギア比の刻印/シールがある。**組む前に仕分けしておく**とミスが減る。

## 3. モーターIDとボーレートの設定

新品モーターは全部 ID=1 で出荷される。バス上で区別するため、**1個ずつ**コントローラーに繋いで固有IDを焼く。値はEEPROM（不揮発）に書かれるので**一度だけ**でよい。

📹 公式動画: [Setup motors video](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/setup_motors_so101_2.mp4)

### 3-1. 各アームのUSBポートを特定する

コントローラーをUSB＋電源で繋ぎ、以下を実行。指示が出たらUSBを抜く:

```bash
lerobot-find-port
```

出力例:

```
Finding all available ports for the MotorBus.
['/dev/tty.usbmodem575E0032081', '/dev/tty.usbmodem575E0031751']
Remove the USB cable from your MotorsBus and press Enter when done.
The port of this MotorsBus is /dev/tty.usbmodem575E0032081
```

→ 表示された `/dev/tty.usbmodem...` が、そのアーム（Follower or Leader）のポート。**両アーム分メモしておく**。

> Linuxの場合、権限付与が必要なことがある:
> ```bash
> sudo chmod 666 /dev/ttyACM0
> sudo chmod 666 /dev/ttyACM1
> ```

### 3-2. Follower のモーターIDを焼く

USBと電源をFollowerのボードに接続し、前ステップのポートを指定して実行:

```bash
lerobot-setup-motors \
    --robot.type=so101_follower \
    --robot.port=/dev/tty.usbmodem585A0076841   # ← 特定したポートに置き換え
```

<details><summary>Python API でやる場合</summary>

```python
from lerobot.robots.so_follower import SO101Follower, SO101FollowerConfig

config = SO101FollowerConfig(
    port="/dev/tty.usbmodem585A0076841",
    id="my_awesome_follower_arm",
)
follower = SO101Follower(config)
follower.setup_motors()
```
</details>

**焼く順番（Gripperから逆順に 6→1）**。スクリプトが1個ずつ指示してくる:

- [ ] `Connect the controller board to the 'gripper' motor only` → **グリッパ用モーターだけ**を繋いでEnter → `'gripper' motor id set to 6`
- [ ] `'wrist_roll' motor only` → 繋いでEnter（ID=5）
- [ ] `'wrist_flex'`（ID=4）
- [ ] `'elbow_flex'`（ID=3）
- [ ] `'shoulder_lift'`（ID=2）
- [ ] `'shoulder_pan'`（ID=1）

> ⚠️ **必ず1個だけ**接続する。この時点ではデイジーチェーン（数珠つなぎ）にしない。
> ⚠️ Enterを押す前に毎回**配線を確認**（電源・USB・3ピンケーブル）。基板を動かした拍子に電源が抜けやすい。
> ⚠️ **Waveshareボードは2つのジャンパを `B`（USB）チャンネル側**にセット。

全部焼き終わったら、**各モーターの3ピンを次のモーターへ数珠つなぎ**し、最初のモーター（shoulder pan / ID=1）からボードへ繋ぐ。ボードは土台に取り付ける。

### 3-3. Leader のモーターIDを焼く

同じ手順を Leader でも実行（コマンドの型が `--teleop` になる点だけ違う）:

```bash
lerobot-setup-motors \
    --teleop.type=so101_leader \
    --teleop.port=/dev/tty.usbmodem575E0031751   # ← Leaderのポート
```

<details><summary>Python API でやる場合</summary>

```python
from lerobot.teleoperators.so_leader import SO101Leader, SO101LeaderConfig

config = SO101LeaderConfig(
    port="/dev/tty.usbmodem585A0076841",
    id="my_awesome_leader_arm",
)
leader = SO101Leader(config)
leader.setup_motors()
```
</details>

> 💡 このとき **§2のギア比表に従って正しいモーターを正しいIDに焼く**。IDと物理的な関節配置がここで結びつく。

## 4. 機械組み立て（Joint 1 → Gripper）

各関節に公式動画がある。**向き・はめ込みは動画が正**。ネジ表記は公式の逐語。

**下ごしらえ:** 3Dプリント部品のサポート材を全部除去（小さいドライバーで裏から剥がすと楽）。**モーターを配置したら、組み進める前に3ピンケーブルを1本挿しておく**と後で楽。

### モーターホーンの共通ルール
各モーターに**上下2つのホーン**を付ける。**上ホーンは M3×6mm 1本で固定、下ホーンはネジ不要**（Joint5のみ片側のみ）。

### Joint 1 — 土台/肩 📹[動画](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Joint1_v2.mp4)
- [ ] 上下ホーンを取付（上=M3×6mm 1本、下=ネジ無し）
- [ ] 1個目のモーターを土台にはめる
- [ ] モーターを **M2×6mm（最小ネジ）4本**で固定（上2・下2）
- [ ] 1個目のモーターホルダーを被せ **M2×6mm 2本**（左右各1）で固定
- [ ] 肩(shoulder)パーツを取付
- [ ] 肩を **上M3×6mm 4本＋下M3×6mm 4本**で締結
- [ ] 肩モーターホルダーを追加

### Joint 2 — 肩・上下 📹[動画](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Joint2_v2.mp4)
- [ ] 上下ホーン取付（上=M3×6mm）
- [ ] 2個目モーターを上から差し込む
- [ ] **M2×6mm 4本**で固定
- [ ] 上腕(upper arm)を **各側M3×6mm 4本**で取付

### Joint 3 — 肘 📹[動画](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Joint3_v2.mp4)
- [ ] 上下ホーン取付（上=M3×6mm）
- [ ] モーター3を挿入し **M2×6mm 4本**で固定
- [ ] 前腕(forearm)をモーター3に **各側M3×6mm 4本**で接続

### Joint 4 — 手首・曲げ 📹[動画](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Joint4_v2.mp4)
- [ ] 上下ホーン取付（上=M3×6mm）
- [ ] モーターホルダー4を被せる
- [ ] モーター4を差し込む
- [ ] **M2×6mm 4本**で固定

### Joint 5 — 手首・回転 📹[動画](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Joint5_v2.mp4)
- [ ] モーター5を手首ホルダーに入れ、**前面M2×6mm 2本**で固定
- [ ] **ホーンは片方だけ**取付、**M3×6mm 1本**で固定
- [ ] 手首をモーター4に **両側M3×6mm 4本**で締結

### Gripper（Follower＝グリッパ） 📹[動画](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Gripper_v2.mp4)
- [ ] グリッパをモーター5の手首ホーンに **M3×6mm 4本**で取付
- [ ] グリッパ用モーターを挿入し **各側M2×6mm 2本**で固定
- [ ] 上下ホーン取付（上=M3×6mm、下=ネジ無し）
- [ ] グリッパの爪(claw)を **両側M3×6mm 4本**で取付

### Handle（Leader＝ハンドル/トリガー） 📹[動画](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Leader_v2.mp4)
> Followerが「グリッパ爪」で終わるのに対し、**Leaderは握って操作するためのハンドルとトリガー**で終わる。
- [ ] リーダーホルダーを手首に **M3×6mm 4本**で取付
- [ ] ハンドルをリーダーホルダーに **M2×6mm 1本**で取付
- [ ] グリッパ用モーターを挿入し **各側M2×6mm 2本**、ホーンを **M3×6mm 1本**で固定
- [ ] フォロワートリガーを **M3×6mm 4本**で取付

## 5. キャリブレーション（超重要）

Leaderと Followerが**同じ物理姿勢で同じ数値**を返すように較正する。これが合っていないと、片方のロボットで学習したモデルが別の個体で動かない。

📹 公式動画: [Calibration video](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/calibrate_so101_2.mp4)

**やり方（両アーム共通）:** ①全関節を可動域の**真ん中**に動かす → ②Enter → ③各関節を**可動域いっぱいまで**動かす。

### Follower
```bash
lerobot-calibrate \
    --robot.type=so101_follower \
    --robot.port=/dev/tty.usbmodem58760431551 \  # ← Followerのポート
    --robot.id=my_awesome_follower_arm            # ← 固有名
```

### Leader
```bash
lerobot-calibrate \
    --teleop.type=so101_leader \
    --teleop.port=/dev/tty.usbmodem58760431551 \  # ← Leaderのポート
    --teleop.id=my_awesome_leader_arm
```

<details><summary>Python API でやる場合（Follower例）</summary>

```python
from lerobot.robots.so_follower import SO101FollowerConfig, SO101Follower

config = SO101FollowerConfig(port="/dev/tty.usbmodem585A0076891", id="my_awesome_follower_arm")
follower = SO101Follower(config)
follower.connect(calibrate=False)
follower.calibrate()
follower.disconnect()
```
</details>

## 6. コマンド早見表（実行順）

```bash
# 1. LeRobot導入後、モーターSDK
pip install -e ".[feetech]"

# 2. ポート特定（両アーム分メモ）
lerobot-find-port

# 3. モーターID設定（1個ずつ・デイジーチェーンしない）
lerobot-setup-motors --robot.type=so101_follower  --robot.port=<FOLLOWER_PORT>
lerobot-setup-motors --teleop.type=so101_leader   --teleop.port=<LEADER_PORT>

# 4. （機械組み立て）

# 5. キャリブレーション
lerobot-calibrate --robot.type=so101_follower --robot.port=<FOLLOWER_PORT> --robot.id=my_awesome_follower_arm
lerobot-calibrate --teleop.type=so101_leader  --teleop.port=<LEADER_PORT>   --teleop.id=my_awesome_leader_arm
```

完成 🎉 → 次は実機での学習: 公式[Getting started with real-world robots](https://huggingface.co/docs/lerobot/il_robots)

## 7. つまずきポイント総まとめ

| 症状 / 場面 | 原因・対処 |
| --- | --- |
| ID設定でエラー | ①電源 ②PC↔ボードのUSB ③ボード↔モーターの3ピン を確認。**1個だけ**接続しているか |
| Waveshareで通信しない | 2つのジャンパが **`B`（USB）チャンネル**か確認 |
| Enter前に反応が変 | 基板を動かした拍子に**電源が抜けやすい**。毎回配線確認 |
| Leaderの動きが重い/おかしい | **ギア比違いのモーターを間違った関節に入れている**（§2表）。ID焼き直しではなく物理配置を確認 |
| 学習モデルが別個体で動かない | キャリブレーション不備。真ん中→全可動域の手順をやり直す |
| ID設定は毎回必要？ | 不要。**EEPROMに焼くので一度だけ** |
